## auto 和 decltype

这两个关键字都和类型推导相关。

### auto

- **版本**：C++11
- **基本用法**：`auto x = 表达式;`
- **常见场景**：复杂类型声明、泛型编程
- **注意事项**：必须初始化、不能用于函数参数

```cpp
auto i = 42;  // int
auto p = &i;  // int*
```

### decltype

```cpp
decltype(auto) c1 = a;
```

## final 与 override

此处是关于虚函数继承的改变。

### final

指定某个虚函数不能在派生类中被覆盖，或者某个类不能被派生。该关键字只能使用在虚函数的声明之后，说明它不能被后续的派生类继承。

```cpp
struct Base
{
    virtual void foo();
};

struct A : Base
{
    void foo() final; // Base::foo 被覆盖而 A::foo 是最终覆盖函数
    void bar() final; // 错误：bar 非虚，因此它不能是 final 的
};

struct B final : A // struct B 为 final
{
    void foo() override; // 错误：foo 不能被覆盖，因为它在 A 中是 final 的
};

struct C : B {}; // 错误：B 是 final 的
```

### override

指定一个虚函数覆盖另一个虚函数（做一个声明，实际上只能用于虚函数中，如果不用也是可以的）。

## 尾随返回类型

尾随返回类型是 lambda 表达式返回值推导的基础。

```cpp
template<class T, class U> auto add(T t, U u) -> decltype(t + u);
auto fpif(int) -> int(*)(int);
```
