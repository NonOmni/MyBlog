## 一个简单的结构体定义了 char 和 int 占几个字节

8 个，因为内存对齐。

### 如果想要它占用 5 个字节应该怎么做

```cpp
#pragma pack(1)
```

### 为什么要有内存对齐

1. **硬件原因**：加快 CPU 的处理速度。CPU 是按照块来读取数据的，所以在读取的时候尽可能使用块的整数倍。
2. **平台原因**：不是所有的硬件都可以访问任意地址上的数据，某些平台只能在某些地址处取某些数据类型，否则抛出硬件异常。

### 一个 char 后边空出三个字节的意义

用空间换时间，加快 CPU 的处理速度。

## X86 是大端还是小端

- **大端模式**：高字节排放在内存的低地址端，低字节排放在内存的高地址端。
- **小端模式**：低字节排放在内存的低地址端，高字节排放在内存的高地址端。

**x86 是小端。**

## C++ 三大特性

### 封装

将数据和操作数据的方法进行有机结合，隐藏对象的属性和实现细节，仅对外公开接口来和对象进行交互。

### 继承

可以使用现有类的所有功能，并在无需重新编写原来的类的情况下对这些功能进行扩展。

### 多态

#### 动态多态性

在基类的函数前加上 `virtual` 关键字，在派生类中重写该函数，运行时将会根据对象的实际类型来调用相应的函数。

**虚函数实现原理**：为每个类对象添加一个隐藏成员，隐藏成员中保存了一个指向函数地址数组的指针，称为虚表指针（vptr），这个数组称为虚函数表（vtbl）。即每个类使用一个虚函数表，每个类对象用一个虚表指针。

#### 静态多态性

函数重载（同名函数参数顺序、个数、类型不同）。

## STL 容器的线程安全性

线程安全是指在多线程环境中，共享数据或资源可以在没有额外同步机制的情况下安全地使用。

STL 中大多数容器是不具备线程安全特性的，需要使用同步机制（锁）。

## 哈希表的时间复杂度

O(1)，最坏情况变为 O(n)。

## map 的时间复杂度

O(log n)。

## SendMessage 和 PostMessage 的区别

`PostMessage` 会将消息压入窗口所在线程的消息队列，然后立即返回；而 `SendMessage` 则不经过消息队列，可认为是直接调用了该窗口的窗口过程。因此，当我们需要获得消息处理后的返回值的时候，就要用到 `SendMessage`。

## 什么情况下使用多线程

1. 处理高并发请求
2. 耗时的大任务
3. 异步任务处理，如 GUI 程序中用多线程处理耗时的操作，避免阻塞用户界面

## 有没有办法让代码先于主函数运行

C++ 中全局变量和局部静态变量会在 main 函数之前被调用，可以创建一个全局对象或者静态局部变量，并在构造函数中执行我们希望运行的函数。

```cpp
#include <iostream>

// 全局对象
struct BeforeMain {
    BeforeMain() {
        std::cout << "This is executed before main()" << std::endl;
    }
} beforeMain;

int main() {
    std::cout << "Inside main()" << std::endl;
    return 0;
}
```

## 设计模式

### 单例模式中构造函数是私有的吗

在单例模式（Singleton Pattern）中，构造函数通常是私有的。这是为了防止外部代码通过 `new` 关键字直接创建单例类的实例，从而确保整个应用程序中只有一个实例。

## 析构函数可以为虚函数吗

析构函数可以是虚函数。在 C++ 中，当一个类被设计为基类时，通常会将析构函数声明为虚函数。这样，当通过基类指针删除派生类对象时，会确保调用正确的析构函数。
