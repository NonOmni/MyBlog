## 插入排序

![插入排序](/img/insertion-sort.png)

对于少量元素的排序，它是一个有效的算法。

```cpp
void InsertionSort(int *a, int len)
{
    for (int j = 1; j < len; j++)
    {
        int key = a[j];
        int i = j - 1;
        while (i >= 0 && a[i] > key)
        {
            a[i + 1] = a[i];
            i--;
        }
        a[i + 1] = key;
    }
}
```

## 分析算法

分析算法的结果意味着预测算法需要的资源。

### 插入排序算法的分析

一般来说，算法需要的时间与输入的规模同步增长，所以通常把一个程序的运行时间描述成其输入规模的函数。

> 实际上参与计算的数目越多，插入排序算法的复杂度越大。
